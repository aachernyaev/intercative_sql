DISTINCT

DISTINCT убирает повторяющиеся строки из результата. Если выбрано несколько столбцов, SQL проверяет уникальность всей их комбинации.

Важно: DISTINCT не означает «уникальность первого столбца». Он сравнивает все выражения, перечисленные после SELECT DISTINCT.
