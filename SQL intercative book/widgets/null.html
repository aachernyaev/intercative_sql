NULL и IS NULL

NULL означает, что значение отсутствует или неизвестно. Это не число, не пустая строка и не отдельный тип данных.

TRUEстрока проходит WHERE
FALSEстрока отбрасывается
UNKNOWNстрока тоже отбрасывается
Проверяем столбец
Условие WHERE
Проверка каждой строкиWHERE оставляет только TRUE
Результат

Правило: для проверки отсутствующего значения используй IS NULL или IS NOT NULL. Обычные сравнения с NULL не дают TRUE или FALSE.
