EXISTS и NOT EXISTS

EXISTS проверяет, вернул ли подзапрос хотя бы одну строку. NOT EXISTS оставляет внешнюю строку, только если подзапрос ничего не нашёл.

Какой результат нужен
users AS uнажми на строку
user_idnameподзапрос
orders AS o
order_iduser_idstatusamount
Результат внешнего SELECT

Важно: подзапрос связан с текущим пользователем условием o.user_id = u.user_id. Запись SELECT 1 подчёркивает, что для EXISTS важен сам факт найденной строки, а не значения её столбцов.
