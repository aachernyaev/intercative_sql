ORDER BY и LIMIT

ORDER BY задаёт порядок строк результата. После сортировки LIMIT оставляет только первые N строк.

FROMисходные строки
→
ORDER BYпереставляем
→
LIMITберём первые N

Важно: без ORDER BY порядок строк результата не гарантирован. Если значения ключа одинаковые, добавь второй ключ для однозначного порядка.
