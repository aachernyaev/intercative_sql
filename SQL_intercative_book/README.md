# SQL Interactive Book

Прототип оболочки учебника без заданий и проверки ответов.

Целевой SQL-диалект — **Trino**. В базовых темах используется максимально общий синтаксис, а диалектные особенности функций и типов объясняются в варианте Trino.

## Принцип урока

Каждый экран состоит из трёх частей:

1. название темы;
2. короткое описание и несколько ключевых понятий;
3. интерактивный виджет, в котором можно менять параметры и наблюдать результат.

## Файлы

- `index.html` — оболочка учебника;
- `assets/app.js` — структура глав и уроков;
- `assets/styles.css` — оформление;
- `widgets/` — место для новых самостоятельных виджетов.

Пока учебник подключает существующие HTML-виджеты из родительской папки. Чтобы добавить урок, достаточно внести его описание и путь к виджету в массив `chapters` в `assets/app.js`.
