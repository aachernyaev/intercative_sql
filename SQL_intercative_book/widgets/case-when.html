CASE WHEN

CASE проверяет условия и возвращает значение для каждой строки. Его можно использовать как новое поле или поместить внутрь агрегатной функции.

Результат на таблице orders6 строк

Важно: CASE останавливается на первом истинном WHEN. Если ни одно условие не сработало и ELSE не указан, результатом будет NULL.
