Типы данных и функции

Значение в SQL всегда имеет тип. Посмотри, как Trino преобразует данные через CAST и TRY_CAST, а затем сравни функции округления.

CAST останавливает запрос при невозможном преобразовании. TRY_CAST в такой ситуации возвращает NULL.
Строковое значение · VARCHAR
Тип результата

Тип — это правило, по которому СУБД хранит и интерпретирует значение. Например, строку '42' нельзя сложить с числом, пока она остаётся VARCHAR.

ROUND округляет до ближайшего значения, CEIL — вверх, а FLOOR — вниз.
