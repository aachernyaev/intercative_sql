LIKE и поиск по строке

LIKE сравнивает текст с шаблоном. Без специальных символов нужно полное совпадение; % и _ делают поиск гибким.

Шаблон поиска
''
Регистр текста
lower(title)
и lower('шаблон')
% — ноль или больше любых символов _ — ровно один любой символ
Таблица listings после WHERE
idtitleрезультат LIKE

Важно: шаблон должен описывать всю строку. Поэтому LIKE 'кот' не найдёт «Кот вязка», а LIKE '%кот%' найдёт текст с «кот» в любой позиции.
