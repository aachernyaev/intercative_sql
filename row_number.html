Включайте и выключайте PARTITION BY vertical и ORDER BY event_date, меняйте направление сортировки и смотрите, как меняется нумерация строк.
1. PARTITION BY vertical

Делит таблицу на отдельные окна по vertical. Нумерация начинается заново в каждом окне.

2. ORDER BY event_date

Задает направление, в котором ROW_NUMBER() идет по строкам внутри окна.

3. Направление сортировки

Что такое ROW_NUMBER()?
Функция присваивает каждой строке номер внутри текущего окна. Нумерация всегда начинается с 1.

Текущий запрос
SELECT id, vertical, event_date, contacts, ROW_NUMBER() OVER( PARTITION BY vertical ORDER BY event_date ASC ) AS rn FROM tbl;
Как читать результат
Есть PARTITION BY и ORDER BY.
SQL делит таблицу на окна по vertical, а внутри каждого окна ранжирует строки по event_date: от ранней даты к поздней.

Итог: каждая vertical — отдельное окно, а стрелка показывает направление ранжирования по event_date (ASC).
1. Только OVER()
Одно окно — вся таблица. Порядок строк как в исходных данных.
2. PARTITION BY vertical
Отдельное окно для каждой vertical. Нумерация заново в каждой группе.
3. PARTITION + ORDER
Отдельные окна по vertical, внутри каждого — сортировка по дате.
4. ORDER BY без PARTITION
Одно окно на всю таблицу, но строки ранжируются по дате.
Важно: без ORDER BY порядок строк внутри окна лучше не считать гарантированным. Для учебной демонстрации здесь показан порядок исходной таблицы.
