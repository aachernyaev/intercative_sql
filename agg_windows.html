Как окно «растёт» при ORDER BY
Что происходит?

Каждый dashed-блок в таблице — отдельное окно по vertical.
ORDER BY выключен: агрегат считается сразу по всему окну, поэтому внутри одного окна результат одинаковый у всех строк.

Финальный ORDER BY в конце запроса добавлен только для аккуратного вывода: он не меняет расчёт оконной функции.
